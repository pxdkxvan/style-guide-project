# Руководство по понятной документации

Это руководство помогает писать тексты, по которым пользователь может выполнить
задачу без догадок и дополнительных вопросов.

## Для кого оно создано

- для технических писателей;
- для разработчиков, которые описывают API и настройку продукта;
- для дизайнеров и редакторов интерфейсных текстов;
- для ревьюеров документации.

## Как пользоваться

Начните с голоса и структуры, затем выберите практический раздел. Перед
публикацией пройдите самопроверку. Если локальное правило команды противоречит
этому руководству, зафиксируйте исключение рядом с документом.

!!! note "Главный критерий"
    Хороший текст не демонстрирует знания автора, а сокращает путь читателя к
    результату.
