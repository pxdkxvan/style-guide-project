# Доступность документации

Доступный документ помогает получить одинаковый результат независимо от способа
восприятия страницы и устройства ввода.

## Описывайте изображения

Альтернативный текст передаёт назначение изображения в текущем контексте. Не
начинайте его со слов «картинка» или «изображение»: программа чтения с экрана уже
сообщает тип элемента.

Для декоративного изображения используйте пустое описание. Если схема содержит
важные связи, изложите их в тексте рядом со схемой.

## Не полагайтесь только на цвет

Дополняйте цвет подписью, значком или формой. Формулировка «обязательные поля
отмечены красным» не помогает читателю, который не различает цвет или использует
монохромный экран.

## Делайте ссылки понятными

Текст ссылки должен объяснять назначение без соседнего предложения. Вместо
«подробнее» напишите «требования к паролю». Не вставляйте длинный URL в обычный
абзац, если читателю не нужно копировать сам адрес.

## Сохраняйте правильную иерархию

Не пропускайте уровни заголовков ради визуального размера. Последовательная
иерархия помогает перемещаться по документу с клавиатуры и через список
заголовков в программе чтения с экрана.
