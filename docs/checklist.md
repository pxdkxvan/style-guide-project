# Самопроверка

Перед публикацией убедитесь, что документ соответствует следующим критериям.

## Содержание

- Цель страницы понятна из заголовка и первого абзаца.
- Предварительные условия перечислены до инструкции.
- Каждый шаг содержит одно основное действие.
- Ожидаемый результат можно проверить.
- Термины используются последовательно.

## Оформление

- Заголовки отражают содержание разделов.
- Ссылки объясняют, куда они ведут.
- Изображения имеют осмысленный альтернативный текст.
- Смысл не передаётся только цветом или положением на странице.
- Уровни заголовков образуют последовательную иерархию.
- Примеры кода не содержат секретов и персональных данных.
- MarkdownLint и `mkdocs build --strict` завершаются без ошибок.
