# Структура страницы

## Начинайте с результата

Первый абзац должен отвечать на два вопроса: что получит читатель и когда ему
нужна эта страница. Историю решения и внутреннее устройство размещайте позже.

## Делите материал по задачам

Используйте заголовки, которые называют действие или результат. Раздел
«Подключите уведомления» понятнее, чем раздел «Уведомления».

Обычный порядок инструкции:

1. Кратко обозначьте результат.
2. Перечислите обязательные условия.
3. Дайте последовательность действий.
4. Покажите способ проверить результат.
5. Объясните восстановление после типовой ошибки.

## Сохраняйте независимость страниц

Страница должна быть понятна при переходе из поиска. Расшифровывайте контекст и
давайте ссылки на обязательные предварительные действия.
