# Термины

## Один объект — одно название

Выберите основной термин и применяйте его во всём разделе. Не чередуйте
«учётная запись», «профиль» и «аккаунт», если речь идёт об одном объекте.

## Заимствования

Используйте русский термин, если он привычен аудитории и не искажает смысл.
Названия команд, параметров и элементов API сохраняйте без перевода и оформляйте
как код: `git switch`, `timeout`, `user_id`.

## Сокращения

При первом упоминании напишите полную форму, если сокращение может быть незнакомо
читателю. Общепринятые в целевой аудитории обозначения вроде API или URL можно не
расшифровывать в каждой статье.
