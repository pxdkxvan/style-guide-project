# Примеры кода

## Делайте пример воспроизводимым

Укажите язык блока, обязательные зависимости и место выполнения команды. Читатель
должен понимать, какие значения можно копировать, а какие нужно заменить.

```bash
curl --request GET \
  --url "https://api.example.test/v1/projects" \
  --header "Authorization: Bearer YOUR_TOKEN"
```

В примере `YOUR_TOKEN` — заполнитель. Не используйте действующие ключи, адреса
внутренних сервисов и персональные данные.

## Объясняйте результат

После команды покажите существенную часть ответа или опишите ожидаемое изменение.
Для ошибки приведите способ диагностики, а не только правильный вариант.

## Не перегружайте фрагмент

Оставляйте только строки, необходимые для текущей задачи. Полный рабочий пример
можно вынести в отдельный файл и дать на него ссылку.
