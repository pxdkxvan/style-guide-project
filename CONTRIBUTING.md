# Как предложить изменение

## Перед началом

1. Создайте отдельную ветку от `main`.
2. Сформулируйте одну задачу для одного изменения.
3. Проверьте, нет ли уже похожего правила или примера.

## Требования к тексту

- Обращайтесь к читателю на «вы».
- Начинайте инструкцию с цели или ожидаемого результата.
- Используйте один термин для одного понятия.
- Добавляйте пример, если правило допускает разные трактовки.
- Проверяйте команды в чистом окружении.

## Проверка pull request

Перед отправкой выполните MarkdownLint и строгую сборку MkDocs. В описании pull
request укажите причину изменения, затронутые страницы и результат проверки.
